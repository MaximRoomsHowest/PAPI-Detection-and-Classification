# MUST stay on the 8.4.x line: the serving model is a yolo26s detector and the

# models/serving/best.pt on a clean install (Docker/CI) — do not downgrade.

# drops the libGL/X11 stack — which also lets the Dockerfile skip the libgl1
# system package (audit DCK-D2). The Dockerfile reinstalls THIS exact version
# (read from this file) after ultralytics pulls the GUI build, so keep it here as
# the single source of truth.
opencv-python-headless==5.0.0.93
exifread==3.5.1
# Shared packages/papi geometry helpers are imported by backend state modules.
# Pin explicitly so Docker images do not rely on the root editable install used
# by CI/developer virtual environments.

# ONNX stack — only exercised when PAPI_MODEL_PATH points at a .onnx model (the
# INT8 edge-export serving path); the default .pt path never imports these
# (audit DCK-RE DEP-1).
onnx==1.22.0
# Dependabot proposed 1.26.0, but the latest version resolvable on our index is
# 1.23.2 — pinning a non-existent version would break the image build, so we take
# the installable ceiling (still a bump from 1.20.1). Revisit if the index gains 1.26.x.

# Pinned exactly like every other dependency here so pip-audit and image builds
# stay reproducible.
