# wheel. Kept in their own file so CI's pip-audit can scan them — torch was
# previously pinned inline in the Dockerfile and invisible to the dependency scan

# dropped cu121 wheels); the CI docker smoke loads the real serving checkpoint on
# these pins, which is the compatibility gate for the image.
#

# DB activated two reviewed torch advisories mid-day (2026-06-10T18:02Z):
#   - CVE-2025-3001 (torch.lstm_cell memory corruption, local-only, LOW) —
#     fixed in 2.10.0, so the previous 2.9.0 pin started failing pip-audit.
#   - CVE-2025-3000 (torch.jit.script memory corruption, local-only, LOW) —
#     NO fixed release exists in any version; ignore-listed in ci.yml.
# 2.11.0 over 2.10.0 because PYSEC-2026-139 caps at <=2.10.x — moving to 2.11
# clears it outright and its old ignore-list entry is removed. torchvision
