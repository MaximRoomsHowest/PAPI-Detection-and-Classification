## Method

- **Images → NTFS hardlinks.** Each of the 3,194 frames gets a real directory entry in the twin
  (so file counts match the original exactly) while sharing physical bytes with the source — disk
  added for imagery is **~0**. Hardlinks are read-only in our use; the original file content and
  mtime are never written. Verified `LinkType=HardLink`, same volume (`C:`), original survives link
  removal.
- **Why hardlink instead of path-reference:** Ultralytics resolves a label by swapping
  `/images/`→`/labels/` in the image path. Referencing the original images would make training read
  the original *2-class* labels. Hardlinking the images *into* the twin lets the twin carry its own
  labels (rewritten to 3-class in Phase 3) without touching the source.
- **Labels / CSVs / manifests → real copies** (independent files Phase 3/6 can annotate).
- **Excluded:** `labels.cache` (Ultralytics rebuilds it; a copied cache would go stale the moment a
  label changes), `desktop.ini`/`Thumbs.db`, and the derived `yolo26n_combined/` config (regenerated
  fresh for 3-class in Phase 3).

## Safety verification

- `original_unchanged: true` — the source tree `(file count, total bytes)` signature is identical
  before and after the run. The script only **reads** source files and **creates hardlinks/copies in
  the target**; it never opens a source file for writing.
- Folder structure preserved (`daytime/<video>/{images,labels}` + per-video CSVs).
- The twin is covered by the existing `.gitignore` rule `data/datasets/` (`git check-ignore`
  confirms) — no multi-GB artifact can be committed by accident.

## Notes / limitations

- `_duplication_report.json` reports **logical** `total_bytes` (≈9.57 GB); physical disk added is
  only the labels + CSVs because images are hardlinks.
- The twin currently holds the **original 2-class labels** verbatim. Phase 3 overwrites
  `…/labels/*.txt` in the twin with the geometry-seeded 3-class taxonomy. The original dataset
  remains the untouched 2-class source of truth.
- Re-running is idempotent (existing files are skipped; `--overwrite` to force relink/recopy).
