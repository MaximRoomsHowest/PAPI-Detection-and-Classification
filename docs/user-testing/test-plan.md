# PAPI Live-Demo — User-Test Plan

A hands-on test catalog for the **Live Demo** page. Every input is a real file in this folder (or
generated by a script), paired with its runway and telemetry, and a concrete **expected result**
(angles below are computed from the real drone GPS + runway geometry). Tick **Pass/Fail** as you go.

> The frames + model output are real; the telemetry is the drone's own recorded position (test
> input, not a re-survey). papi_06 geometry is provisional — treat its angle as indicative.

## How to run
1. Start the backend (`apps/backend` → `uvicorn app.main:app --reload`) and the frontend
   (`apps/frontend` → `npm run dev`, http://localhost:5173). Live Demo is the landing flow.
2. Drag a file (or folder) onto the viewer, or use **Upload** / **Upload folder**. Analysis
   **auto-runs**. To run again after changing a parameter, click **Re-run analysis** in the toolbar.
3. When the angle is "unavailable", open the **metadata panel**: choose the runway, then upload a
   telemetry file (`telemetry/…`) or type lat/lon/alt, then **Apply metadata**.

## Performance (be patient — CPU-bound, ~0.4 fps)
Single image ~1–3 s · 10-frame angle-sweep ~20–30 s (one round-trip per image) · short video ~3–8 s.

## 9 · UX / UI & accessibility (the polish pass)
| ID | Check | Expected | Pass/Fail |
|----|-------|----------|-----------|
| U1 | Re-run discoverable | Toolbar shows a labeled **"Re-run analysis"** button; disabled tooltip explains why | |
| U2 | Result provenance | Every result (incl. a still image) shows a top strip: **Runway: …** and **Telemetry: …** | |

| U8 | Empty / error consistency | Idle shows the empty prompt; errors show a clear inline banner; no stale result under an error | |
| U9 | Responsive | At 360 px and 768 px the toolbar wraps, the result panel goes single-column, nothing clips | |
| U10 | i18n | Switch EN/DE/NL/FR — all labels (Re-run, provenance, hints) translate, no `undefined` | |
